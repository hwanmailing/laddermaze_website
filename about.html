Our studio

Arcade Game Lab

Arcade Game Lab is an independent game studio built by a team of passionate developers who love retro-style games and modern gameplay.

We create simple, yet deep and exciting games that bring back the fun of classic arcade games while offering new challenges and experiences.

Our goal is simple:
To make games that are fun, challenging,
and memorable.

Our journey

From an Idea to a Game

It all started with a simple idea:
“Let’s make a game that feels like an adventure.”

That idea grew into Arcade Game Lab.
With hard work, countless tests, and a lot of coffee, we created Ladder Maze — our first game.

This is just the beginning. We’re already working on new ideas, new worlds, and more exciting games.
