私たちについて Arcade Game Lab

遊びからひらめきを。情熱からゲームを。

私たちは、冒険、パズル、アクションを愛するプレイヤー向けに楽しくてやりがいのあるゲームを作成する独立系ゲーム スタジオ Arcade Game Lab です。

スタジオについて

Arcade Game Lab

Arcade Game Labは、レトロスタイルのゲームと最新のゲームプレイを愛する情熱的な開発者のチームによって構築された独立したゲームスタジオです。

私たちは、新しい挑戦と経験を提供しながら、古典的なアーケードゲームの楽しさを取り戻す、シンプルでありながら奥深くエキサイティングなゲームを作成します。

私たちの目標は単純です。
楽しくてやりがいのあるゲームを作るには、
そして思い出深い。

大切にしていること

私たちの信念

楽しさを第一に

ゲームは何よりも楽しくなければなりません。私たちはプレイヤーの楽しみをすべての活動の中心に置いています。

挑戦する楽しさ

私たちは、考えさせ、計画を立て、改善させるゲームが大好きです。適切なチャレンジがゲームを存続させます。

情熱を込めて

私たちはあらゆるゲームに好奇心と配慮をもたらします。私たちは、共有したくなる冒険を創造します。

成長を続ける

私たちはプレイヤーの声に耳を傾け、フィードバックから学び、より良いゲームを作るために挑戦し続けます。

これまでの歩み

アイデアがゲームになるまで

それはすべて、「冒険のようなゲームを作ろう」という単純なアイデアから始まりました。

そのアイデアは Arcade Game Lab に成長しました。私たちは、ハードワーク、無数のテスト、そして大量のコーヒーを使って、最初のゲームである はしご迷路 を作成しました。

これはほんの始まりにすぎない。私たちはすでに新しいアイデア、新しい世界、そしてよりエキサイティングなゲームに取り組んでいます。
