隐私政策

网站、游戏保存和广告——简单解释。

以下是 Arcade Game Lab 网站和 梯子迷宫 如何处理信息以及哪些内容会保留在您的设备上。

1网站

您无需帐户或输入个人详细信息即可浏览本网站。我们不会向这些页面添加广告跟踪器、分析工具或跟踪 cookie。

该站点托管在 GitHub Pages 上。 GitHub 记录访问者的 IP 地址以确保安全,如其中所述 托管文档.

页脚的电子邮件链接仅打开您的电子邮件应用程序;它不提交网站表格。如果您选择发送消息,我们会收到您的电子邮件地址和您包含的任何内容,以便我们回复。

2游戏记录

梯子迷宫 在您的设备上保存分数、达到的最高楼层并记录日期以显示您的最佳结果。这些记录存储在本地,而不是发送到 Arcade Game Lab 评分服务器。不需要玩家帐户。

本地记录将保留,直到应用程序的存储数据被删除。清除应用程序数据或删除应用程序可以将其删除。设备备份和恢复设置也可能会影响是否保留这些记录。

3应用内购买

如果您进行应用内购买,则Apple或Google处理付款。游戏会检查购买状态并保存购买的功能是否已解锁。 Arcade Game Lab 未收到您的支付卡详细信息。

4游戏内广告·AdMob

梯子迷宫使用Google AdMob来展示游戏内广告。 Google 移动广告 SDK 可以收集和共享 IP 地址、设备或广告标识符、广告视图和交互以及崩溃或性能信息。 IP 地址还可用于估计大致位置。

Google 使用该信息来传送和测量广告、支持广告分析并帮助防止欺诈。使用的信息以及广告是否个性化取决于平台、权限和适用的隐私设置。

参见 Google 的隐私政策 以及 AdMob 数据披露 Android 和 iOS.

5广告隐私设置

您的设备的隐私设置提供对广告标识符或应用程序跟踪的控制,具体取决于操作系统。限制个性化并不一定会停止广告或广告投放、衡量和预防欺诈所需的处理。

Google 在中解释了其广告控制 广告 — 隐私和条款.

6政策更新

该页面描述了网站和游戏的当前信息处理。如果这些功能发生变化,本说明和下面的日期将会更新。
